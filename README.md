# 늘봄 교실 허브

교실에서 사용할 수 있는 타이머, 스톱워치, 모둠 점수판, 소음 측정기, PDF 글자 수 분석기, 로컬 일기장을 한곳에 모은 정적 웹 앱입니다.

## 실행 방법

`dist/index.html`을 정적 웹 서버로 제공하면 됩니다. 마이크 기능과 일부 파일 기능은 보안 컨텍스트(HTTPS 또는 localhost)에서 동작합니다.

## 개인정보 및 보안

- 로그인이나 서버 데이터베이스를 사용하지 않습니다.
- 점수판·타이머 설정과 일기 데이터는 사용자 브라우저 또는 사용자가 선택한 로컬 폴더에 저장됩니다.
- 실제 학생 이름 등 식별 가능한 개인정보 입력은 권장하지 않습니다.
- PDF 분석은 브라우저 안에서 처리됩니다. PDF.js 모듈은 cdnjs에서 불러옵니다.

자세한 요구사항과 개인정보 고려사항은 [DEVELOPMENT_SPEC.md](DEVELOPMENT_SPEC.md)를 참고하세요.
